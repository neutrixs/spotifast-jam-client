Spotifast with jams, 0.17.102: invite links now work on Windows. Built on Spotifast 0.17.1.

**Download:** [Windows](https://github.com/neutrixs/spotifast-jam-client/releases/download/v0.17.102/spotifast-v0.17.102-x86_64-pc-windows-msvc.msi) · [Windows ARM](https://github.com/neutrixs/spotifast-jam-client/releases/download/v0.17.102/spotifast-v0.17.102-aarch64-pc-windows-msvc.msi) · [Linux](https://github.com/neutrixs/spotifast-jam-client/releases/download/v0.17.102/spotifast-v0.17.102-x86_64-unknown-linux-gnu.tar.gz) · [AppImage](https://github.com/neutrixs/spotifast-jam-client/releases/download/v0.17.102/spotifast-0.17.102-x86_64.AppImage)

Installing it on Windows replaces Spotifast if you already have it, keeping your settings and sign-in. Windows may warn that the installer is from an unknown publisher: choose **More info**, then **Run anyway**. Copies of 0.17.101 offer this update themselves.

## Fixed

- **Opening a jam invite link joins the jam on Windows.** Windows passed the link on in a slightly different shape, which Spotifast turned away, so **Open in Spotifast** opened nothing.
